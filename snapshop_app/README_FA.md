# ربات هوشمند مدیریت قیمت اسنپ‌شاپ (SnappShop Smart Price Bot)

این پروژه یک ربات **خودکار، هوشمند و بدون نیاز به رابط گرافیکی (Headless)** برای مدیریت قیمت و پایش محصولات فروشندگان در فروشگاه اینترنتی **اسنپ‌شاپ (SnappShop)** است که قابلیت اجرا به صورت مداوم بر روی **سرور مجازی (VPS)** و مدیریت از طریق **ربات تلگرام** را دارا می‌باشد.

---

## 🌟 قابلیت‌های اصلی

1. **موتور قدرتمند Playwright + ضد تشخیص (Stealth)**
   - استفاده از **Playwright Async API** به همراه تکنیک‌های ضد ربات جهت کاهش خطر مسدودی حساب.
   - حفظ و ذخیره نشست کاربری در فایل `storage_state.json` (ورود مجدد نیازی به دریافت کد ندارد).

2. **احراز هویت و ورود OTP هوشمند از طریق تلگرام**
   - در صورت انقضای نشست کاربری، ربات پیامک کد تایید (OTP) را مستقیماً در چت تلگرام از شما دریافت می‌کند.

3. **کنترل و گزارش‌دهی از طریق ربات تلگرام**
   - **ارسال فایل:** امکان ارسال فایل Excel/CSV حاوی تنظیمات محصولات در تلگرام.
   - **دستورات:** `/status` (مشاهده وضعیت)، `/run_now` (اجرای فوری)، `/set_interval` (تنظیم زمان‌بندی).
   - **گزارشات:** ارسال گزارش کامل تغییرات قیمت و هشدارهای خطا به چت تلگرام.

4. **تنظیمات اختصاصی قیمت برای هر محصول**
   - پشتیبانی از ستون‌های سفارشی:
     - `قیمت حداقل` (Min Price): کف قیمت مجاز محصول.
     - `قیمت حداکثر` (Max Price): سقف قیمت مجاز محصول.
     - `گام کاهش قیمت` (Step Decrease): میزان کاهش قیمت در صورت وجود رقیب ارزان‌تر.
     - `گام افزایش قیمت` (Step Increase): میزان افزایش قیمت در صورت گران‌تر شدن یا عدم وجود رقیب.

5. **بهینه‌سازی مصرف منابع (قانون ۲۴ ساعته)**
   - محصولات فاقد رقیب تنها **هر ۲۴ ساعت یک‌بار** بررسی می‌شوند تا از مصرف بیهوده منابع سرور جلوگیری شود.
   - محصولات دارای رقیب طبق زمان‌بندی (مثلاً هر ۲۰ دقیقه) به صورت زنده پایش می‌شوند.

6. **آماده‌سازی کامل جهت اجرا روی VPS (Linux / Docker)**
   - دارای فایل `snapshop.service` برای اجرای خودکار در Linux (`systemd`).
   - دارای `Dockerfile` جهت اجرای ایزوله در داکر.

## 📁 ساختار پروژه

```text
snapshop_app/
├── main.py                  # نقطه ورود اصلی ربات و دمن VPS
├── requirements.txt         # نیازمندی‌های پروژه
├── .env.example             # قالب متغیرهای محیطی
├── snapshop.service         # فایل سرویس systemd جهت اجرا در VPS
├── Dockerfile               # کانفیگ داکر
└── src/
    ├── config/
    │   └── settings.py      # تنظیمات و بارگذاری متغیرهای محیطی
    ├── core/
    │   ├── browser.py       # مدیریت مرورگر Playwright و کوکی‌ها
    │   ├── auth.py          # ورود به پنل فروشنده و دریافت کد OTP
    │   ├── scraper.py       # دانلود/آپلود اکسل و استخراج قیمت بای‌باکس
    │   ├── pricing.py       # موتور محاسبه قیمت رقابتی و گام‌ها
    │   └── database.py      # دیتابیس SQLite برای پایش قانون ۲۴ ساعته
    ├── telegram/
    │   ├── bot.py           # ساخت ربات تلگرام
    │   ├── handlers.py      # هندلرهای دریافت فایل و دستورات
    │   └── notifier.py      # ارسال گزارشات و هشدارها به تلگرام
    └── scheduler/
        └── job_runner.py    # زمان‌بند اجرای مداوم
```

## 🚀 راهنمای نصب و اجرا

### ۱. تنظیم متغیرهای محیطی
فایل `.env.example` را به `.env` تغییر نام دهید و اطلاعات خود را وارد کنید:
```bash
TELEGRAM_BOT_TOKEN=123456789:ABC...
TELEGRAM_ADMIN_CHAT_ID=123456789
SNAPSHOP_PHONE_NUMBER=09120000000
SNAPSHOP_PASSWORD=YourPassword
SNAPSHOP_COMPANY_NAME=نام_فروشگاه_شما
```

### ۲. نصب پیش‌نیازها
```bash
pip install -r requirements.txt
playwright install chromium
```

### ۳. اجرا
```bash
python main.py
```
